# Stabilization of n+m PDEs using continuum observer-based output feedback

The purpose of this MATLAB code is to reproduce the simulation results from Section 4 of the paper "Output-feedback backstepping stabilization of large-scale n+m coupled hyperbolic
PDEs via continuum kernels and observer" by Jukka-Pekka Humaloja and Nikolaos Bekiaris-Liberis which is accepted for publication in Automatica. A preprint of the paper is available in [arXiv](https://arxiv.org/abs/2503.08209).

The mathematical background and the documentation for the codes are briefly desribed in the file "codesdoc.pdf.".

## Requirements

The codes require MATLAB.

## Usage

The simulation results of Section 4 can be reproduced by running the script n2contobsv.m.
